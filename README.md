# 🎮 Snake – Water – Gun Game (Tkinter GUI)

A simple and interactive **Snake–Water–Gun game** built using **Python and Tkinter**, featuring a clean dashboard UI, real-time score tracking, and classic game logic.

This project demonstrates **Python logic building**, **GUI development**, and **event-driven programming**.

## 🧠 Game Rules

- 🐍 **Snake beats Water**
- 💧 **Water beats Gun**
- 🔫 **Gun beats Snake**
- Same choice → 🤝 Draw

---

## 🧑‍🎓 Who Should Use This Project

- Beginners learning Python
- Students practicing Tkinter GUI
- Anyone understanding event-driven programming

---

## 🛠️ Tech Stack

- **Language:** Python  
- **GUI Library:** Tkinter  
- **Logic:** Dictionary-based comparison  
- **Randomization:** `random` module
